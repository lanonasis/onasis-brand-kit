## What we build

Lan Onasis spans several product families. Each repository here belongs to a
single ecosystem; product repos stay visibly connected to the parent brand.

- **Memory-as-a-Service** — durable, governed memory infrastructure
- **V-Secure** — secure communications
- **VortexCore** — core processing
- **Onasis Gateway** — connectivity
- **SeftecHub** — developer tools and infrastructure
- **LZero (L0)** — sub-product mark, subordinate to the Lan Onasis ecosystem
- **Financial technology solutions** — business enablement

## Repository conventions

- **Naming:** lowercase, product-first (`onasis-brand-kit`, `v-secure`,
  `vortexcore`, `onasis-gateway`). No `LAN-` prefixes.
- **Topics:** every repo carries `lanonasis` plus domain topics
  (`fintech`, `security`, `infrastructure`, `developer-tools`).
- **Licensing:** per-repo; default `MIT`. Confirm before publishing.
- **Brand assets:** use only canonical assets from
  [onasis-brand-kit](https://github.com/lanonasis/onasis-brand-kit) — see the
  [asset manifest](/documentation/ASSET_MANIFEST.md) and the
  [social namespace pack](/documentation/SOCIAL_NAMESPACE_PACK.md).
