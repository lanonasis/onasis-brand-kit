How It Works

The brand kit uses a fully automated Node.js build pipeline. Edit a single SVG source file and regenerate all 44 assets instantly — no design software required. 

# Edit SVG sources in:
source/svg-sources/
  ├── primary-logo.svg      # Full circle logo + wordmark
  ├── icon-standalone.svg   # Transparent icon (L + globe/gear)
  ├── app-icon.svg          # Navy square app icon
  └── favicon-master.svg    # Simplified favicon

# Then regenerate all 44 assets:
bun run build:assets

# Or build everything (CSS + assets):
bun run build
