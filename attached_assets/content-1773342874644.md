# LAN Onasis Brand Kit

[Permalink: LAN Onasis Brand Kit](https://www.npmjs.com/package/@lanonasis/brand-kit#lan-onasis-brand-kit)

Official brand assets and guidelines for LAN Onasis.

## ⚡ Quick Start

[Permalink: ⚡ Quick Start](https://www.npmjs.com/package/@lanonasis/brand-kit#-quick-start)

- **Ready-to-use assets**: PNG files in all folders
- **Need extraction**: SVG logos and icons (see [ASSET\_STATUS.md](https://github.com/lanonasis/onasis-brand-kit/blob/HEAD/ASSET_STATUS.md))
- **Design files**: Located in `source/design-boards/`
- **Documentation**: Additional docs in `documentation/`

## 🚀 Usage

[Permalink: 🚀 Usage](https://www.npmjs.com/package/@lanonasis/brand-kit#-usage)

### For Designers

[Permalink: For Designers](https://www.npmjs.com/package/@lanonasis/brand-kit#for-designers)

1. Extract individual assets from `source/design-boards/`
2. Follow TODO files in each folder for specific requirements
3. Optimize SVGs before committing

### For Developers

[Permalink: For Developers](https://www.npmjs.com/package/@lanonasis/brand-kit#for-developers)

1. Use PNG files from appropriate folders
2. Check `05_DEVELOPER_ASSETS/` for code snippets
3. See `ASSET_STATUS.md` for what's ready vs pending

### For Brand Managers

[Permalink: For Brand Managers](https://www.npmjs.com/package/@lanonasis/brand-kit#for-brand-managers)

1. Review `documentation/LAN_ONASIS_BRAND_STRATEGY.md`
2. Check `ASSET_STATUS.md` for extraction progress
3. Approve extracted assets before production use

## ⚠️ Important Notes

[Permalink: ⚠️ Important Notes](https://www.npmjs.com/package/@lanonasis/brand-kit#%EF%B8%8F-important-notes)

- **DO NOT** use files from `source/design-boards/` directly in production
- **DO** extract and optimize individual assets from design boards
- **DO** follow the naming conventions in TODO files
- **DO** test assets at their intended display sizes

## 🔧 Extraction Tools

[Permalink: 🔧 Extraction Tools](https://www.npmjs.com/package/@lanonasis/brand-kit#-extraction-tools)

- Adobe Illustrator (recommended)
- Inkscape (free alternative)
- Sketch
- Figma
- SVGO for optimization

[Permalink: 🔒 Branch Protection](https://www.npmjs.com/package/@lanonasis/brand-kit#-branch-protection)

- Required pull request reviews
- Dismiss stale reviews on new commits
- Required status checks
- No force pushes allowed
- No deletions allowed
