# Lan-Onasis Social Media Guidelines

## Platform Strategy & Voice

### LinkedIn
**Purpose:** Primary B2B communication channel
**Tone:** Professional, insightful, industry-focused
**Content Mix:**
- 40% Industry insights and thought leadership
- 30% Product updates and features
- 20% Company culture and team spotlights
- 10% Partner success stories

### Twitter/X
**Purpose:** Tech community engagement and real-time updates
**Tone:** Technical, engaging, conversational
**Content Mix:**
- 35% Technical tips and insights
- 25% Product announcements
- 20% Industry news and commentary
- 20% Developer engagement

### GitHub
**Purpose:** Developer community engagement
**Tone:** Technical, precise, helpful
**Content Mix:**
- Documentation updates
- Code samples
- Integration guides
- Community contributions

### Medium
**Purpose:** Long-form technical content
**Tone:** In-depth, educational, authoritative
**Content Mix:**
- Technical deep-dives
- Case studies
- Integration tutorials
- Industry analysis

## Content Guidelines

### Technical Content
- Use clear, concise language
- Include code snippets where relevant
- Link to documentation
- Highlight key features and benefits
- Use proper technical terminology

### Business Content
- Focus on value proposition
- Include ROI metrics when possible
- Reference customer success stories
- Highlight industry trends
- Use data visualizations

### Visual Guidelines
- Use brand colors consistently
- Include product screenshots
- Create infographics for complex topics
- Use custom illustrations for technical concepts
- Maintain professional photo style

## Safe Zones
- **Twitter/X**: Avoid placing critical text within 10% of image edges.
- **LinkedIn**: Avoid placing text within 16px of top/bottom edges.
- **Instagram**: Avoid placing text within 10% of image edges for posts; for Stories, avoid top 15% and bottom 10%.
- **Facebook**: Avoid placing critical text within 10% of image edges.

### Expanded Brand Voice/Copy Guidelines
- **Tone Modifiers**:
  - Instagram: Casual, friendly, visually focused.
  - LinkedIn: Formal, professional, insight-driven.
  - Twitter/X: Conversational, technical, engaging.
  - Medium: Authoritative, educational, detailed.
- **Copywriting Principles**:
  - Use active voice.
  - Focus on benefits, not features.
  - Keep sentences short and clear.
  - Avoid jargon unless necessary.

## File Organization Guide

### Folder Structure
```
social-media/
├── templates/
│   ├── twitter/
│   ├── linkedin/
│   └── instagram/
├── assets/
│   ├── logos/
│   ├── icons/
│   └── illustrations/
└── campaigns/
    ├── product-launches/
    ├── technical-updates/
    └── success-stories/
```

### Naming Conventions
- Templates: `[Platform]-[Purpose]-[Version].png` (e.g., `twitter-product-update-v1.png`)
- Assets: `[Type]-[Name].[ext]` (e.g., `logo-primary.svg`, `icon-alert.png`)
- Campaigns: `[CampaignName]-[Date]` (e.g., `product-launch-Q4-2025/`)

### Usage Instructions
- Place new templates in the appropriate platform folder.
- Add new assets to the corresponding subfolder in `assets/`.
- Organize campaign-specific files in the `campaigns/` folder, using the naming convention above.
