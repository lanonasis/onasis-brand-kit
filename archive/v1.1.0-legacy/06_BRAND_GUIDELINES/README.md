## How to Use
### 4-Tier Logo System
- **Primary**: Detailed emblem + text (formal, print). Minimum width ~2 inches.
- **Secondary**: Simplified horizontal (web headers, email).
- **Icon/Symbol**: Square mark for apps/social/favicons (16–512px).
- **Monogram**: Minimal letterform for micro contexts and patterns.

### Color Palette
- **Primary Navy**: #1B365D
- **Accent Green**: #00D4AA
- **Gold Accents**: #FFD700 (primary logo only)

### File Formats
- **SVG**: Preferred for web use
- **PNG**: For general use
- **ICO**: For legacy favicons

## Accessibility Guidelines
- Ensure sufficient contrast between text and background (minimum 4.5:1 for text)
- Provide alternative text for all images and graphics
- Use semantic HTML elements where possible
- Test with screen readers to ensure proper reading order
- Consider providing high-contrast versions for users with visual impairments
- Avoid using color alone to convey information
- Ensure all interactive elements are keyboard navigable
- Provide text alternatives for any decorative elements

## Notes
- Always maintain sufficient clear space around logos (≥ height of the “L”).
- Use brand colors consistently across all assets.
- Follow file format recommendations based on intended use case.
