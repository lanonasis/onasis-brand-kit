Brand Guidelines

4-Tier Logo System
- Primary: Detailed emblem + text (formal, print). Min ~2in width.
- Secondary: Simplified horizontal (web headers, email).
- Icon/Symbol: Square mark for apps/social/favicons (16–512px).
- Monogram: Minimal letterform for micro contexts and patterns.

Color Palette
- Primary Navy: #1B365D
- Accent Green: #00D4AA
- Gold Accents: #FFD700 (primary logo only)

File Formats
- SVG for web (preferred), PNG for general use, ICO for legacy favicons.
