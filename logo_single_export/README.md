# Logo Single Export Directory

This directory contains various logo export formats and sizes for development purposes.

## Structure

- `png_transparent/` - PNG logos with transparent backgrounds
- `png_white_bg/` - PNG logos with white backgrounds
- `webp/` - WebP format logos for web optimization
- `preview/` - Preview images and thumbnails

## Usage

These logo exports are intended for development and testing purposes. They are not included in the published npm package but can be used for:

- Application development
- Testing different logo formats
- Creating custom logo variations
- Development and staging environments

## Guidelines

- Maintain consistent quality across all formats
- Use appropriate compression settings
- Follow naming conventions
- Keep file sizes optimized for web use
